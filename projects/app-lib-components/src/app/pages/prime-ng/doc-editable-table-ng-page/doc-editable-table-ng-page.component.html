Tabla Editable

Componente de tabla editable que permite modificar datos directamente en la tabla. Soporta dos modos de edición: por celda (edición individual de cada celda) y por fila (edición completa de la fila). Incluye soporte para múltiples tipos de controles inline, validaciones, agregar y eliminar filas.

Importación

import {{ '{' }} TableNgComponent {{ '}' }} from 'lib-components';
import type {{ '{' }} ITableNgConfig, ITableNgData, IEditTableNgConfig {{ '}' }} from 'lib-components';
import {{ '{' }} ETypeInput {{ '}' }} from 'lib-components';

Configuración Básica

Para habilitar la edición en una tabla, necesitas proporcionar la configuración editConfig con isEnabled: true y especificar el tipo de edición ('cell' o 'row'). 

editConfig: {{ '{' }}
  isEnabled: true,
  type: 'cell' | 'row',
  inlineControls: {{ '{' }}
    // Configuración de controles por campo
  {{ '}' }}
{{ '}' }}

Edición por Celda

En el modo 'cell', cada celda se puede editar individualmente haciendo clic en ella. Los cambios se guardan automáticamente al salir de la celda o después de un debounce. 

editConfig: {{ '{' }}
  isEnabled: true,
  type: 'cell',
  inlineControls: {{ '{' }}
    name: {{ '{' }} typeInput: ETypeInput.TEXT {{ '}' }},
    email: {{ '{' }} typeInput: ETypeInput.EMAIL {{ '}' }},
    age: {{ '{' }} typeInput: ETypeInput.NUMBER {{ '}' }},
    salary: {{ '{' }} 
      typeInput: ETypeInput.CURRENCY,
      currencyConfig: {{ '{' }} currency: 'USD', locale: 'en-US' {{ '}' }}
    {{ '}' }},
    status: {{ '{' }}
      typeInput: ETypeInput.SELECT,
      selectConfig: {{ '{' }}
        options: [
          {{ '{' }} code: 'Activo', name: 'Activo' {{ '}' }},
          {{ '{' }} code: 'Inactivo', name: 'Inactivo' {{ '}' }}
        ]
      {{ '}' }}
    {{ '}' }},
    active: {{ '{' }} typeInput: ETypeInput.SWITCH {{ '}' }},
    date: {{ '{' }} typeInput: ETypeInput.DATE {{ '}' }}
  {{ '}' }},
  cellEditConfig: {{ '{' }}
    defaultTableNgData: {{ '{' }}
      // Fila por defecto para agregar nuevas filas
    {{ '}' }},
    isDisabledAddButton: false,
    isDisabledDeleteButton: false
  {{ '}' }}
{{ '}' }}

Nota: En modo celda, puedes hacer clic directamente en cualquier celda para editarla. El botón de eliminar aparece en cada fila.

Edición por Fila

En el modo 'row', toda la fila se edita al mismo tiempo. Debes hacer clic en el botón de editar para entrar en modo de edición, y luego usar los botones de guardar o cancelar. 

editConfig: {{ '{' }}
  isEnabled: true,
  type: 'row',
  inlineControls: {{ '{' }}
    // Misma configuración que en modo cell
  {{ '}' }},
  rowEditConfig: {{ '{' }}
    defaultTableNgData: {{ '{' }}
      // Fila por defecto para agregar nuevas filas
    {{ '}' }},
    isDisabledAddButton: false,
    isDisabledDeleteButton: false,
    rowErrorConfig: {{ '{' }}
      isEnabled: true,
      fieldErrors: {{ '{' }}
        // Errores de validación por fila
      {{ '}' }}
    {{ '}' }}
  {{ '}' }}
{{ '}' }}

Nota: En modo fila, solo puedes editar una fila a la vez. El botón de agregar se deshabilita mientras hay una fila en edición.

Tipos de Controles Inline

El componente soporta múltiples tipos de controles inline a través de ETypeInput:

Tipo Descripción Configuración Adicional
TEXT Campo de texto simple -
EMAIL Campo de email con validación -
NUMBER Campo numérico -
CURRENCY Campo de moneda currencyConfig (currency, locale, minFractionDigits, maxFractionDigits)
DECIMAL Número decimal -
DATE Selector de fecha dateConfig (minDate, maxDate, selectionMode)
DATETIME_LOCAL Selector de fecha y hora dateConfig
SELECT Selector desplegable selectConfig (options, optionLabel)
MULTISELECT Selector múltiple multiSelectConfig (options, optionLabel)
SWITCH Interruptor on/off -
TEXTAREA Área de texto multilínea textareaConfig (rows, cols, variant)
OTP Campo OTP (One-Time Password) otpConfig (length, mask, integerOnly)

Eventos

El componente emite varios eventos para manejar los cambios en los datos:

Evento Tipo Descripción
outputEditData ITableNgData<T>[] Se emite cuando se modifica cualquier dato en la tabla (con debounce de 300ms)
outputRowDataChange ITableNgData<T> Se emite cuando se guarda una fila en modo 'row'
outputAddRow ITableNgData<T>[] Se emite cuando se solicita agregar una nueva fila
outputDeleteRow ITableNgData<T> Se emite cuando se elimina una fila
outputRowInlineChange T Se emite cuando cambia un valor inline en modo 'row' (antes de guardar)
outputIsEditing boolean Indica si hay alguna fila en modo de edición
outputHandleEditInitButton ITableNgData<T> Se emite cuando se inicia la edición de una fila 
<lib-table-ng
  [data]="tableData"
  [config]="tableConfig"
  [editConfig]="editConfig"
  (outputEditData)="onEditData($event)"
  (outputRowDataChange)="onRowDataChange($event)"
  (outputAddRow)="onAddRow($event)"
  (outputDeleteRow)="onDeleteRow($event)"
/>

Agregar y Eliminar Filas

El componente incluye botones para agregar y eliminar filas. Para agregar filas, necesitas proporcionar defaultTableNgData en la configuración de edición. 

cellEditConfig: {{ '{' }}
  defaultTableNgData: {{ '{' }}
    id: '',
    rowData: {{ '{' }}
      id: '',
      name: '',
      email: '',
      age: 0,
      salary: 0,
      status: 'Activo',
      active: false,
      date: null
    {{ '}' }},
    raw: {{ '{' }}{{ '}' }},
    onClick: () => {{ '{' }}{{ '}' }}
  {{ '}' }},
  isDisabledAddButton: false,
  isDisabledDeleteButton: false
{{ '}' }}

Nota: En modo 'cell', las nuevas filas se agregan automáticamente si hay defaultTableNgData. En modo 'row', se emite el evento outputAddRow para que manejes la lógica de agregado.

Validaciones y Errores

En modo 'row', puedes configurar validaciones y mostrar errores por campo usando rowErrorConfig: 

rowEditConfig: {{ '{' }}
  rowErrorConfig: {{ '{' }}
    isEnabled: true,
    fieldErrors: {{ '{' }}
      'row-id-1': {{ '{' }}
        'name': {{ '{' }}
          fieldName: 'name',
          message: 'El nombre es requerido'
        {{ '}' }},
        'email': {{ '{' }}
          fieldName: 'email',
          message: 'El email no es válido'
        {{ '}' }}
      {{ '}' }}
    {{ '}' }}
  {{ '}' }}
{{ '}' }}

Nota: Cuando hay errores, el botón de guardar se deshabilita y muestra un tooltip con los errores.

Interfaz IEditTableNgConfig

Referencia completa de todas las propiedades disponibles en la configuración de edición:

Propiedad Tipo Descripción
isEnabled boolean Habilita o deshabilita la funcionalidad de edición (requerido)
type 'cell' | 'row' Tipo de edición: por celda o por fila (requerido)
inlineControls IInlineControls? Configuración de controles inline por campo. Es un objeto donde la clave es el nombre del campo y el valor es InlineControlConfig
rowEditConfig IRowEditConfig<T>? Configuración específica para modo 'row'
cellEditConfig IConfigEditCellAndRow<T>? Configuración específica para modo 'cell'

Interfaz IInlineControls

IInlineControls es un objeto donde cada clave corresponde al nombre de un campo en rowData y el valor es una configuración InlineControlConfig: 

type IInlineControls = Record<string, InlineControlConfig>

// Ejemplo:
inlineControls: {{ '{' }}
  'name': {{ '{' }} typeInput: ETypeInput.TEXT {{ '}' }},
  'email': {{ '{' }} typeInput: ETypeInput.EMAIL {{ '}' }},
  'age': {{ '{' }} typeInput: ETypeInput.NUMBER {{ '}' }},
  'salary': {{ '{' }}
    typeInput: ETypeInput.CURRENCY,
    currencyConfig: {{ '{' }} currency: 'USD', locale: 'en-US' {{ '}' }}
  {{ '}' }}
{{ '}' }}

Mejores Prácticas

  • Modo Cell vs Row: Usa modo 'cell' para ediciones rápidas y frecuentes. Usa modo 'row' cuando necesites validar múltiples campos antes de guardar.
  • Configuración de Controles: Siempre proporciona inlineControls para los campos que quieres editar. Los campos sin configuración usarán el tipo TEXT por defecto.
  • Manejo de Eventos: Escucha outputEditData para guardar cambios automáticamente o outputRowDataChange para guardar solo cuando se confirma la edición de una fila.
  • Agregar Filas: Proporciona siempre defaultTableNgData con valores por defecto apropiados para facilitar la creación de nuevas filas.
  • Validaciones: En modo 'row', usa rowErrorConfig para mostrar errores de validación antes de permitir guardar.
