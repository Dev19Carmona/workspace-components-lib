Speed Dial NG Component

Componente de acciones flotantes basado en PrimeNG. Permite mostrar acciones rápidas con direcciones configurables, tooltips y personalización del botón principal.

Importación

import {{ '{' }} SpeedDialNgComponent {{ '}' }} from 'lib-components';

Uso Básico

El componente requiere el input configInput con la configuración del speed dial. El botón principal muestra/oculta las acciones secundarias. 

<lib-speed-dial-ng [configInput]="basicSpeedDialConfig" />

Dirección de despliegue

Puedes configurar la dirección de expansión con direction: 'up', 'down', 'left' o 'right'.

Direction: up

Direction: left

Botón principal personalizado

Con buttonProps puedes cambiar icono, severidad, forma y demás props del botón principal.

Tooltips

Puedes definir tooltips globales con tooltipOptions y también tooltips por ítem usando items[].tooltipOptions.

Interfaz ISpeedDialNgConfig

Referencia de propiedades disponibles para configurar el componente.

Propiedad Tipo Descripción
items ISpeedDialNgItem[] Listado de acciones a mostrar en el speed dial (requerido)
buttonProps ButtonProps? Props del botón principal (icono, severidad, estilo, etc.)
tooltipOptions TooltipOptions? Configuración global de tooltips para las acciones
style Record<string, string>? Estilos inline para posicionar el speed dial en su contenedor
direction 'up' | 'down' | 'left' | 'right'? Dirección de expansión de las acciones (por defecto: down)

Interfaz ISpeedDialNgItem

Cada elemento extiende MenuItem de PrimeNG, por lo que soporta propiedades como label, icon, command, disabled, entre otras.

Propiedad Tipo Descripción
label string? Texto de la acción
icon string? Icono PrimeIcons de la acción
command (event) => void? Función que se ejecuta al seleccionar la acción
tooltipOptions TooltipOptions? Tooltip específico del ítem
isSpeedDial boolean? Flag extendida del wrapper para identificar ítems de speed dial
