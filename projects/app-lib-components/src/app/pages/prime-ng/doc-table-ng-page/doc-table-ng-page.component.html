Table NG Component

Componente de tabla avanzado basado en PrimeNG con funcionalidades como paginación, filtros globales y por columna, selección múltiple, edición inline, lazy loading, exportación a Excel/PDF y mucho más.

Importación

import {{ '{' }} TableNgComponent {{ '}' }} from 'lib-components';
import type {{ '{' }} ITableNgConfig, ITableNgData {{ '}' }} from 'lib-components';

Uso Básico

El componente requiere un array de ITableNgData y una configuración ITableNgConfig.

<lib-table-ng
  [data]="tableData"
  [config]="tableConfig"
/>

Filtro Global

Habilita un campo de búsqueda global que filtra en múltiples columnas simultáneamente.

globalFilterConfig: {{ '{' }}
  isEnabled: true,
  globalFilterFields: ['name', 'email', 'status']
{{ '}' }}

Advanced Filters (Identifier)

El componente soporta filtros avanzados por identificadores desde toolbar usando globalFilterConfig.advancedIdentifierFiltersConfig. Al habilitarlo, aparece un botón de filtros avanzados que abre un modal para seleccionar identifiers. 

globalFilterConfig: {{ '{' }}
  isEnabled: true,
  globalFilterFields: ['identifier', 'name', 'email', 'status'],
  advancedIdentifierFiltersConfig: {{ '{' }}
    isEnabled: true
  {{ '}' }}
{{ '}' }}

Importante: para que funcione correctamente, tus filas deben incluir el campo rowData.identifier. El filtro interno se aplica sobre rowData.identifier con el modo arrayStringFilter.

Toolbar Speed Dial

También puedes inyectar acciones rápidas en el toolbar de la tabla usando toolbarSpeedDialButtons, que internamente consume ISpeedDialConfig[] (ver implementación en TableNgComponent, líneas 71-72). 

toolbarSpeedDialButtonsExample: ISpeedDialConfig[] = [
  {{ '{' }}
    direction: 'bottom',
    mainButton: {{ '{' }} icon: 'pi pi-plus', severity: 'help', rounded: true {{ '}' }},
    buttons: [
      {{ '{' }} icon: 'pi pi-file-excel', onClick: () => {{ '{' }} ... {{ '}' }} {{ '}' }},
      {{ '{' }} icon: 'pi pi-refresh', onClick: () => {{ '{' }} ... {{ '}' }} {{ '}' }},
      {{ '{' }} icon: 'pi pi-filter', onClick: () => {{ '{' }} ... {{ '}' }} {{ '}' }}

  {{ '}' }}
]
<lib-table-ng
  [data]="basicTableData()"
  [config]="basicTableConfig"
  [toolbarSpeedDialButtons]="toolbarSpeedDialButtonsExample"
/>

selectionTableConfig: {{ '{' }}

Botón de Refresh

Agrega un botón de actualización que permite recargar los datos de la tabla mediante un callback async.

refreshConfig: {{ '{' }}
  isEnabled: true,
  callback: async () => {{ '{' }}
    const newData = await this.loadTableData()
    this.tableData.set(newData)
  {{ '}' }}
{{ '}' }}

El callback se ejecuta cuando se hace clic en el botón de refresh. Debe ser una función async que actualice el signal data del componente padre. La tabla se actualizará automáticamente cuando cambien los datos.

Paginación

Configura la paginación de la tabla con opciones personalizables de filas por página.

paginationConfig: {{ '{' }}
  paginator: true,
  rows: 5,
  rowsPerPageOptions: [5, 10, 20]
{{ '}' }}

La paginación se muestra automáticamente en la parte inferior de la tabla.

Lazy Loading

Para tablas con grandes volúmenes de datos, puedes usar lazy loading para cargar datos bajo demanda.

lazyLoadingConfig: {{ '{' }}
  isEnabled: true,
  totalRecords: 1000
{{ '}' }}

El evento lazyLoading se emite cuando se necesita cargar más datos.

Lazy Loading con Descarga de Excel

Cuando usas lazy loading, puedes configurar la descarga de Excel para que cargue todos los datos que coincidan con los filtros aplicados desde el servidor, en lugar de solo los datos visibles en la tabla. 

lazyLoadingConfig: {{ '{' }}
  isEnabled: true,
  totalRecords: 100,
  excelLazyLoadingConfig: {{ '{' }}
    callback: (filters: Record<string, any>) => {{ '{' }}
      // Retorna un Observable con todos los datos filtrados
      return this.loadExcelData(filters);
    {{ '}' }}
  {{ '}' }}
{{ '}' }},
excelConfig: {{ '{' }}
  isEnabled: true,
  name: 'usuarios-lazy'
{{ '}' }}

El callback excelLazyLoadingConfig recibe los filtros aplicados en la tabla y debe retornar un Observable con todos los datos que coincidan con esos filtros. La tabla automáticamente descargará el Excel con esos datos. 

// Manejo del evento lazyLoading para cargar datos paginados
onLazyLoad(event: ILazyLoadResponse): void {{ '{' }}
  const skip = event.metaPagination.skip ?? 0;
  const limit = event.metaPagination.limit ?? 10;
  
  // Extraer filtros del evento
  const filters: Record<string, any> = {{ '{}' }};
  Object.entries(event.filters).forEach(([key, value]) => {{ '{' }}
    if (value && typeof value === 'object' && 'value' in value) {{ '{' }}
      const filterKey = key.replace('rowData.', '');
      filters[filterKey] = (value as any).value;
    {{ '}' }}
  {{ '}' }});

  this.loadLazyData(filters, skip, limit).subscribe((data) => {{ '{' }}
    this.tableData.set(data);
  {{ '}' }});
{{ '}' }}

Nota: Este ejemplo simula 100 registros. Al cambiar de página, aplicar filtros o hacer clic en el botón de Excel, se cargarán los datos correspondientes. El Excel descargará todos los registros que coincidan con los filtros aplicados, no solo los visibles en la página actual.

Edición Inline

Permite editar celdas o filas directamente en la tabla. A continuación se muestran ejemplos funcionales de edición por celda y por fila. 

editConfig: {{ '{' }}
  isEnabled: true,
  type: 'cell' | 'row',
  inlineControls: {{ '{' }}
    // configuración de controles inline
  {{ '}' }}
{{ '}' }}

Tabla editable por celda

En modo cell, puedes hacer clic en cualquier celda para editarla directamente. 

<lib-table-ng
  [data]="editableCellTableData()"
  [config]="editableCellTableConfig"
  [editConfig]="editableCellEditConfig"
/>

Tabla editable por fila

En modo row, se habilita la edición completa de una fila con acciones de guardar/cancelar. 

<lib-table-ng
  [data]="editableRowTableData()"
  [config]="editableRowTableConfig"
  [editConfig]="editableRowEditConfig"
/>

Prueba rápida: `ETypeInput.INPUT` y toggle masivo en header

La columna name usa lib-inline-input con typeCell + rowDataInput. La columna isActive usa INPUT con SWITCH en cada fila; en el header, con inputConfig.isActive, aparece un switch maestro que llama a applyBulkBooleanToColumn (todas las filas quedan en true o false). 

// Configuración por fila (ITableNgData)
{{ '{' }}
  rowData: {{ '{' }} name: 'Prueba input', ... {{ '}' }},
  typeCell: {{ '{' }} name: ETypeInput.INPUT {{ '}' }},
  rowDataInput: {{ '{' }} name: {{ '{' }} typeInput: ETypeInput.TEXT {{ '}' }} {{ '}' }}
{{ '}' }}
// Celda INPUT (solo ngModel por fila)
@case (ETypeInput.INPUT) {
  <lib-inline-input
    [(ngModel)]="item.rowData[key]"
    [config]="item.rowDataInput?.[key] ?? {typeInput: ETypeInput.TEXT}"
  ></lib-inline-input>
}

// Header maestro (SWITCH / CHECKBOX) con inputConfig
<lib-inline-input
  [ngModel]="booleanColumnHeaderReflectValue(key)"
  (ngModelChange)="applyBulkBooleanToColumn($event, key)"
  [config]="inlineConfigCheckHeader(...)"
/>
// TableNgComponent (resumen)
applyBulkBooleanToColumn(value: boolean, columnKey: string) {
  this.data.update((rows) => rows.map((row) => ({ ...row, rowData: { ...row.rowData, [columnKey]: value } as T })))
}

Prueba el switch de la columna Activo en el header y en una fila: el del header debe poner todas las filas al mismo valor booleano.

Configura filtros específicos para cada columna con diferentes tipos y modos de coincidencia.

filterConfigByKey: {{ '{' }}
  'status': {{ '{' }}
    isEnabled: true,
    primeNgColumnFilterConfig: {{ '{' }}
      type: 'text',
      matchMode: 'contains'
    {{ '}' }}
  {{ '}' }}
{{ '}' }}

Labels Personalizados (Multiidioma)

Puedes personalizar todos los mensajes y labels de la tabla usando labelsConfig. Si no se proporcionan, se usarán los valores por defecto en inglés. 

labelsConfig: {{ '{' }}
  customPageReport: 'Mostrando {first} a {last} de {totalRecords} registros',
  selectedItemsLabel: 'Has seleccionado',
  recordsLabel: 'registros',
  loadingMessage: 'Cargando...',
  noDataMessage: 'No hay información disponible'
{{ '}' }}

Propiedades de ITableNgLabelsTitleConfig

Propiedad Tipo Valor por defecto Descripción
customPageReport string? 'Showing {first} to {last} of {totalRecords} entries' Template para el reporte de paginación. Usa {first}, {last}, {totalRecords}
selectedItemsLabel string? 'You have selected' Label para el mensaje de items seleccionados
recordsLabel string? 'records' Label para la palabra "registros" o "items"
loadingMessage string? 'Loading...' Mensaje mostrado durante la carga de datos
noDataMessage string? 'No information available' Mensaje mostrado cuando no hay datos disponibles
